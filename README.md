## Getting started

Open a machine's documentation for its download, file checksums, and network settings. Run vulnerable machines in an isolated lab network and follow the release page's guidance before importing an image.

Each future machine can have its own directory under `vms/`, with a README covering its release, setup, and downloads. VM images and other large archives are not stored in this repository.
